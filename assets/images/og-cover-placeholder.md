# OG Cover Image — Required

Filename: og-cover.webp  
Dimensions: 1200 × 630px  
Referenced by: og:image and twitter:image meta tags in index.html

## How to generate

1. Open the live site in Chrome at 1200px viewport width
2. Take a full-page screenshot of the hero section (above the fold only)
3. Crop to exactly 1200 × 630px
4. Convert to WebP (target < 200KB)
5. Save as assets/images/og-cover.webp and delete this file

## Content guidance

Should show the hero headline "Sukwana Mweemba & Partners / Proven Legacy." on the
Bright Snow (#f7f9f9) background. Ensure the Burnt Rose headline text is clearly
legible at thumbnail size (Facebook, WhatsApp, LinkedIn link previews).
